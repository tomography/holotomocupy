=======
Credits
=======


If you use holotomocupy, please cite the bilinear Hessian paper
:cite:`Nikitin:26`, which describes the joint object/probe/position solver
this package implements:

    Viktor Nikitin et al., "Scalable joint X-ray nano-holotomography
    reconstruction with the bilinear Hessian method", *Optica* **13**\ (9),
    1814-1826 (2026).

Related work: :cite:`Nikitin:22` and :cite:`Nikitin:24`.
